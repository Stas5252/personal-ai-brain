# Grounding: как материалы владельца попадают в каждый ответ

## Проблема, которую это решает

В репозитории лежат 57 PDF курса (`материалы для ии`) и 40 конспектов в
`src/brain/knowledge`. Они индексируются (`scripts/ingest_course_corpus.py`,
`scripts/seed_vetted_knowledge.py`), но читал этот индекс только один путь —
`BrainService.process_chat`. Движки (promotion, sales, shooting, content,
proactive) вызывают `LLMProvider.chat_completion` напрямую со своим шаблоном и
профилем, поэтому 18 из 32 guided-функций отвечали, ни разу не открыв базу
знаний. Материалы были на месте, проиндексированы и не использовались.

## Как это работает

`src/brain/services/knowledge_grounding.py` подключён в
`LLMProvider.chat_completion` — единственной точке, через которую проходят все
обращения к модели.

1. Берётся последний вопрос пользователя (включая текстовую часть vision-запроса).
2. `KnowledgeEngine.retrieve` возвращает до `BRAIN_GROUNDING_TOP_K` фрагментов:
   гибридный поиск ChromaDB + FTS5 с лексическим фолбэком.
3. Фрагменты вставляются отдельным system-сообщением с названием источника и
   страницей или слайдом.
4. Для обычных ответов модель просят закончить строкой `📚 Источники: …` и
   перечислить только реально использованные материалы. Для строгих
   JSON-контрактов движков эта инструкция не добавляется, чтобы не сломать разбор.
5. Названия использованных источников остаются в
   `LLMProvider.last_grounding_sources`.

Если промпт уже содержит `МАТЕРИАЛЫ ИЗ БАЗЫ ЗНАНИЙ` (так делает `process_chat`),
grounding не дублируется и контекст не тратится дважды.

## Политика отказов

Grounding — добавка, а не зависимость. Нет базы, холодный вектор-индекс, битый
фрагмент — ответ уйдёт без ссылок, но не упадёт. Все ошибки логируются и
возвращают исходный промпт без изменений.

## Переключатели

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `BRAIN_GROUNDING_ENABLED` | `true` | полностью выключает grounding |
| `BRAIN_GROUNDING_TOP_K` | `3` | сколько фрагментов подмешивать в вызов |
| `BRAIN_GROUNDING_MAX_CHARS` | `2400` | бюджет выдержек на один вызов |

## Как проверить

```bash
pytest -q tests/brain/test_knowledge_grounding.py
python scripts/ingest_course_corpus.py --report
curl -s -H "Authorization: Bearer $BRAIN_API_KEY" localhost:8000/health/knowledge | jq
```

После полной индексации задайте боту вопрос по теме конкретного урока: в ответе
должна появиться строка `📚 Источники:` с названием материала и страницей.
Если строки нет — либо корпус ещё не осел (смотрите `--report`), либо вопрос не
совпал ни с одним фрагментом.
