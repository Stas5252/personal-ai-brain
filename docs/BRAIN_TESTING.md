## 1. Методология и стандарты тестирования

Для Stage 2 была сформирована строгая программа приемочных E2E-тестов. В отличие от симуляций с поддельными оценками "10/10", каждый тест выполняет реальные вызовы движков через API и валидирует физические изменения в базе данных `data/brain.db`.

### 8 тестовых групп:
1. **Memory Engine** (6 тестов) — допуск, ретривал, обновление, разрешение конфликтов, удаление, фильтрация шума.
2. **User Profile & Onboarding** (2 теста) — прохождение 10-шагового интервью, валидация полей.
3. **Knowledge Engine & RAG** (4 теста) — слои, многослойный ретривал, `SourceTrace`, предотвращение галлюцинаций.
4. **Style Engine** (3 теста) — эталоны, директивы, Style Benchmark (5 метрик), детекция стоп-слов.
5. **Agent Router** (5 тестов) — маршрутизация фото-интентов, контента, продаж, клиентов и проектов.
6. **Context Engine** (3 теста) — взвешенное ранжирование, изоляция проектов и клиентов.
7. **Security** (2 теста) — устойчивость к prompt injection, проверка Bearer-токена.
8. **Observability** (1 тест) — сквозной аудит телеметрии и трассировки запроса.

```bash
python -m pytest tests/brain/test_brain_suite.py -v
```

```bash
python tests/brain/run_brain_benchmark.py
```
