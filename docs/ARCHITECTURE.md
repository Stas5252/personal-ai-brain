## 2. Описание подсистем и компонентов

### 2.1. Gateway и Безопасность
- **FastAPI Core:** Обрабатывает все REST и WebSocket соединения, обеспечивает потоковую передачу токенов (Server-Sent Events).
- **JWT Authentication:** Каждому авторизованному сеансу выдается криптографически подписанный токен (`WEBUI_SECRET_KEY`).
- **Изоляция:** Регистрация может быть закрыта после создания аккаунта администратора (`ENABLE_SIGNUP=false`).

### 2.2. Уровень абстракции провайдеров (Model Provider Abstraction)
- Open WebUI взаимодействует с моделями через стандартизированный клиент `OpenAI-compatible API`.
- **Текущий провайдер:** Google Gemini через `https://generativelanguage.googleapis.com/v1beta/openai/`.
- **Преимущество архитектуры:** При добавлении или смене провайдера (OpenAI GPT-4o, Anthropic Claude 3.7 Sonnet, DeepSeek V3, Groq, или локальный Ollama) логика приложений, память и база знаний остаются неизменными. Достаточно прописать базовый URL и API-ключ в настройках или `.env`.

### 2.3. Долговременная память (Memory Engine)
- Open WebUI автоматически извлекает ключевые факты о пользователе из контекста бесед (профессия, предпочтения, стек, личные правила).
- Факты векторизуются и сохраняются в персистентной памяти пользователя.
- При начале любого нового чата релевантные факты автоматически инжектируются в системный промпт, создавая ощущение непрерывного знакомства.

### 2.4. База знаний и RAG (Knowledge Engine)
- Загрузка файлов (PDF, DOCX, TXT, MD, CSV).
- Встроенный ETL-пайплайн: разделение на смысловые фрагменты (chunking) с настраиваемым размером и перекрытием.
- Локальная генерация векторных представлений через оптимизированный FastEmbed (ONNX runtime на CPU, не тратит VRAM видеокарты).
- Гибридный семантический поиск: векторное сходство + полнотекстовое совпадение.

### 2.5. Слой инструментов (Native Tool Calling & Functions)
- Модели с поддержкой Function Calling (включая `gemini-2.5-flash`) получают список доступных инструментов в формате JSON Schema.
- Модель возвращает структурированный вызов инструмента (имя функции + аргументы).
- Open WebUI исполняет функцию и возвращает результат в контекст для формирования итогового ответа.
- Поддерживается создание кастомных Python функций прямо в веб-интерфейсе (Pipes, Actions, Filters).

### 2.6. Сохранность данных (Storage Persistence)
- Все данные монтируются в изолированный Docker volume `open-webui-data`.
- База данных: SQLite (опционально мигрируемая на PostgreSQL при масштабировании на команду).
- При перезапуске или обновлении контейнера все чаты, пользователи, документы и настройки сохраняются на 100%.
