# Структура репозитория и политика веток

## Это один проект

`Stas5252/personal-ai-brain` — один репозиторий и один продукт. Рабочая версия всегда находится в ветке `master`.

## Состояние веток на 10 сентября 2026

- `master` — единственная актуальная production-ветка.
- `feature/yaishka-parity-plus` — завершённая ветка PR #3; изменения объединены в `master` squash-коммитом.
- `fix/reliability-security-20260907` — завершённая ветка PR #1; все её коммиты входят в историю `master`.
- `fix/honest-document-image-ingestion-20260907` — завершённая ветка; её tip-коммит `992645e` и предыдущие исправления входят в историю `master`.

Три немастер-ветки не являются отдельными проектами и не нужны для запуска. Их можно безопасно удалить после сохранения ссылок на PR/коммиты; данные из `master` не исчезнут.

## Политика далее

1. Пользователь клонирует и разворачивает только `master`.
2. Короткая ветка создаётся только для изменения с PR и удаляется после merge.
3. Незавершённая работа помечается draft PR, а не новой долгоживущей веткой.
4. Релиз подтверждается зелёным CI и live checklist; название ветки не является версией продукта.

## База знаний

Production-seed использует только пять файлов из `scripts/seed_vetted_knowledge.py`. Это собственное проверенное ядро. Старые учебные конспекты остаются историческими материалами репозитория, но больше не считаются авторитетным built-in corpus и не индексируются новым чистым развёртыванием.

Пользовательские документы загружаются отдельно через `/знания` или API и не смешиваются с редакционным авторством ядра.
