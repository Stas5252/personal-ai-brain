## 1. Проблема нейросетевых клише и задача Style Engine

Типичные LLM без специализированного стилевого движка генерируют однотипные тексты:
- Навязчивые банальности (*"погрузитесь в мир волшебства"*, *"уникальный опыт"*);
- Уменьшительно-ласкательные суффиксы (*"красоточка"*, *"фоточки"*, *"моментики"*);
- Перегрузка эмодзи через слово (✨📸💫🔥🤍);
- Монотонный синтаксис (одинаковая длина предложений, отсутствие авторского ритма).

**Style Engine** превращает абстрактный языковой вывод в живой авторский слог конкретного фотографа, опираясь на:
1. Хранилище эталонов (Exemplars Vault).
2. Динамическую сборку стилевых инструкций в системный промпт.
3. Количественный бенчмарк стиля (Style Benchmark) по 5 измеримым метрикам.

---

## 2. Хранилище эталонов (Exemplars Vault)

В базе данных `style_exemplars` хранятся реальные примеры авторских текстов, размеченные по типам и категориям:

### Типы эталонов (`ExemplarType`):
- **`GOOD_EXAMPLE`**: идеальный образец авторского стиля для подражания.
- **`BAD_EXAMPLE`**: антипример (текст, который ни в коем случае нельзя воспроизводить).
- **`NEUTRAL_EXAMPLE`**: нейтральный информационный шаблон (для технических справок).

### Категории эталонов (`ExemplarCategory`):
- `POST` — посты в блог / Telegram / социальные сети;
- `REELS_SCRIPT` — сценарии динамичных коротких роликов;
- `STORIES` — серии разговорных и визуальных сторис;
- `COMMERCIAL_OFFER` — коммерческие предложения и пакеты услуг;
- `DIRECT_MESSAGE` — переписка с клиентами в личных сообщениях;
- `PHOTO_REVIEW` — рецензии и разборы фоторабот.

## 3. Динамическая сборка стилевых директив

Метод `build_style_instructions(profile, category)` формирует блок промпта, настраивающий модель перед генерацией:

```markdown
### СТИЛЬ И ТОНАЛЬНОСТЬ АВТОРА:
- Тон: Деликатный, поддерживающий, профессиональный, без давления
- Юмор: Тонкий, самоироничный, без сарказма
- Структура текста: Короткие емкие абзацы (1-3 строки) с воздухом
- Длина предложений: средняя ~14 слов, ритмичный слог
- Эмодзи: Сдержанно (не более 1-2 на пост), нейтральные символы
- Пунктуация: Точки, тире, без многоточий и тройных восклицаний
- ЗАПРЕЩЕННЫЕ СЛОВА И КЛИШЕ: красоточка, волшебные кадры, уникальный прайс, невероятная атмосфера

### ЭТАЛОННЫЕ ПРИМЕРЫ АВТОРСКОГО ТЕКСТА (GOOD EXAMPLES):
--- Пример 1 (Пост: Съемка как терапия) ---
Каждая съемка — это не про позирование. Это про разрешение себе быть настоящей. Без заученных поз и натянутых улыбок. Запись на октябрь в директ.
```

## 4. Математическая модель Style Benchmark (5 метрик)

Каждый сформированный текст валидируется методом `evaluate_benchmark(text, profile, forbidden_words)`:

| Метрика | Формула расчета | Целевой диапазон | Вес в скоре |
| :--- | :--- | :---: | :---: |
| **1. Vocabulary Similarity** | Пересечение словаря ответа с эталонами и авторским глоссарием | $\ge 0.70$ | $0.30$ |
| **2. Sentence Rhythm** | $1.0 - \frac{|\text{AvgLen} - \text{TargetLen}|}{15.0}$ | $\text{AvgLen} \in [10, 18]$ слов | $0.25$ |
| **3. Emoji Density** | 1-5 эмодзи = 1.0; 0 эмодзи = 0.8; >5 эмодзи = штраф 0.15 за каждый | $1 - 4$ эмодзи на текст | $0.20$ |
| **4. CTA Presence** | Наличие глаголов действия (*напиши, директ, запись, бронь, сохраняй*) | 1.0 (есть) / 0.5 (нет) | $0.25$ |
| **5. Forbidden Violations** | Прямое вхождение запрещенных клише и стоп-слов | **0 нарушений** | Штраф: $-0.40$ за каждое |

### Итоговый скор бенчмарка:

$$\text{Overall Score} = \max\left(0.0, \; 0.30 \cdot \text{Vocab} + 0.25 \cdot \text{Rhythm} + 0.20 \cdot \text{Emoji} + 0.25 \cdot \text{CTA} - 0.40 \cdot \text{Violations}\right)$$

При наличии хотя бы двух запрещенных слов скор падает ниже $0.60$, сигнализируя о браке генерации.

## 5. Схема таблицы SQLite (`style_exemplars`)

```sql
CREATE TABLE IF NOT EXISTS style_exemplars (
    id TEXT PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    exemplar_type TEXT NOT NULL,
    category TEXT NOT NULL,
    tags_json TEXT,
    notes TEXT,
    created_at TEXT NOT NULL
);

CREATE INDEX IF NOT EXISTS idx_exemplars_cat ON style_exemplars(category);
CREATE INDEX IF NOT EXISTS idx_exemplars_type ON style_exemplars(exemplar_type);
```
