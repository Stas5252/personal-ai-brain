# Personal AI Brain: Маршрутизатор агентов (Agent Router)

**Проект:** Персональный AI-ассистент фотографа и визуального креатора  
**Модуль:** Agent Router (`src/brain/engines/agent_router.py`)  
**Статус:** Реализован и верифицирован (5/5 тестов группы Router: 100% PASS)  

---

## 1. Концепция специализированных ролей

Монолитный системный промпт не способен одинаково качественно отвечать на технический вопрос по физике студийного света, отрабатывать возражение «дорого» в переписке с клиентом и писать вирусный сценарий для Reels.

**Agent Router** выполняет семантическую классификацию входящего запроса пользователя и динамически подбирает:
1. **Основной интент (`primary_intent`);**
2. **Вторичные интенты (`secondary_intents`);**
3. **Специализированный фокус промпта (`specialized_system_prompt`);**
4. **Необходимый инструментарий (`required_tools`).**

## 3. Алгоритм взвешенной классификации

1. Запрос анализируется словарем взвешенных маркеров `INTENT_KEYWORDS`.
2. Длинным и составным терминам (например, *"студийный свет"*, *"схема света"*, *"статус подготовки"*) присваивается удвоенный вес ($weight = 2$).
3. Рассчитывается суммарный вес по каждому интенту:
   - Лидирующий интент становится `primary_intent`.
   - Топ-3 следующих интентов формируют список `secondary_intents`.
4. Если ни один маркер не сработал, назначается интент по умолчанию: `GENERAL` с базовой уверенностью `confidence = 0.85`.

---

## 4. Автоматическое подключение инструментов (`required_tools`)

- Если в запросе обнаружены интенты `PHOTO` или `MOODBOARD`, в список требуемых инструментов добавляется `image_generation` (подготовка генерации эскизов света или мудбордов).
- Если обнаружен интент `KNOWLEDGE_SEARCH`, активируется `knowledge_retrieval` (поиск точных цитат в иерархической базе знаний).
