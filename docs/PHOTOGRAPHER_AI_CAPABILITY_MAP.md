# Photographer AI Capability Map (Матрица возможностей Personal AI Brain)

В данном документе зафиксированы все ключевые продуктовые возможности Personal AI Brain для фотографа, benchmarked против специализированной системы «Яишка».

## 1. Обзор статусов
- **IMPLEMENTED**: Возможность полностью реализована в коде, протестирована сквозными сценариями и не использует имитаций.
- **PARTIAL**: Базовый пайплайн реализован, расширение зависит от внешних API (например, живое зрение VLM).
- **NOT_IMPLEMENTED**: Честно задекларировано отсутствие аппаратной/облачной интеграции без фальсификации.
