## 1. Концепция и продуктовый принцип

AI Brain — это центральный оркестрационный слой персонального ассистента. В отличие от простых систем с монолитным системным промптом, AI Brain отделяет **интерфейсы** от **интеллекта, контекста и памяти**.

### Главный архитектурный принцип:
```
                      ПОЛЬЗОВАТЕЛЬСКИЕ КЛИЕНТЫ
                                 |
              +------------------+------------------+
              |                  |                  |
           Web UI             Telegram             MAX
         (Open WebUI)        (aiogram 3)       (Мобильный)
              |                  |                  |
              +------------------+------------------+
                                 |
                                 v
                        PERSONAL AI BRAIN API
                                 |
      +--------------------------+--------------------------+
      |                          |                          |
USER PROFILE             MEMORY POLICY (10 типы)     HIERARCHICAL KNOWLEDGE
(Онбординг, табу)         (Допуск, конфликты)          (6 слоев, трассировка)
      |                          |                          |
      +--------------------------+--------------------------+
                                 |
                                 v
                           AGENT ROUTER
                 (13 специализированных интентов)
                                 |
                                 v
                          CONTEXT ENGINE
           (Взвешенное ранжирование & Квотирование бюджета)
                                 |
                                 v
                           STYLE ENGINE
           (Эталоны, ритм, анти-клише, 5 метрик бенчмарка)
                                 |
                                 v
                          UNIVERSAL POLICY
                (ZERO захардкоженных личных данных)
                                 |
                                 v
                         LLM PROVIDER POOL
              (Google Gemini / Open WebUI / Резерв)
                                 |
                                 v
                        OBSERVABILITY TRACE
              (Телеметрия: intent, sources, latency)
```

Единый мозг исключает дублирование бизнес-логики: если фотограф обновил прайс или зафиксировал договоренность с клиентом через Web UI, бот в Telegram мгновенно видит те же самые данные из единой SQLite базы `brain.db`.

## 2. Разделение ответственности (Separation of Concerns)

1. **Open WebUI (Foundation Layer):**
   - Предоставляет графический интерфейс чата, сессии пользователей, локальную серверную транскрибацию речи (Faster Whisper) и хранилище бинарных файлов.
   - Подключает AI Brain через OpenAI-совместимый интерфейс `/v1/chat/completions` как модель `personal-ai-brain`.
2. **AI Brain Core (`src/brain/`):**
   - Управляет жизненным циклом профиля, долговременной памяти, базой знаний, проектами и клиентами.
   - Выполняет динамическую маршрутизацию и сборку контекста перед отправкой в языковую модель.
3. **Model Provider:**
   - Каскадный пул моделей (`gemini-2.5-flash`, `gemini-3.5-flash`, `gemini-3.5-flash-lite`) с защитой от rate-limit квот.

## 3. Компоненты системы

| Модуль | Расположение | Назначение |
| :--- | :--- | :--- |
| **Profile Engine** | `src/brain/engines/profile_engine.py` | Интерактивное 10-шаговое интервью онбординга, валидация Pydantic, стоп-слова. |
| **Memory Engine** | `src/brain/engines/memory_engine.py` | Политика допуска (SAVE/UPDATE/IGNORE/TEMP), взвешенный ретривал, Superseding конфликтов. |
| **Knowledge Engine**| `src/brain/engines/knowledge_engine.py`| 6 иерархических слоев (Global, Pro, Personal, Business, Project, Client), сквозные Source Traces. |
| **Style Engine** | `src/brain/engines/style_engine.py` | Хранилище эталонов (GOOD/BAD), Style Benchmark (5 метрик качества авторского слога). |
| **Agent Router** | `src/brain/engines/agent_router.py` | Классификация 13 интентов, подбор специализированных промптов и инструментов. |
| **Context Engine** | `src/brain/engines/context_engine.py` | Взвешенный скоринг ($0.45 rel + 0.35 imp + 0.20 rec$), лимиты токенов. |
| **System Policy** | `src/brain/prompts/system_policy.py` | Универсальная политика без единого захардкоженного личного факта. |
| **Brain API** | `src/brain/api/` | REST API (21 эндпоинт) на FastAPI для интеграции клиентов и телеметрии. |

## 4. Персистентность и данные

- База данных: SQLite (`data/brain.db`).
- Изоляция данных проектов и клиентов: каждый факт памяти или фрагмент знаний может быть привязан к `project_id` и `client_id`, гарантируя, что детали частных съемок не попадают в контекст других заказчиков.
