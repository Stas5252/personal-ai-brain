# 🧠 Personal AI Brain — AI-Ассистент для Фотобизнеса

> **Персональный интеллектуальный мозг и бизнес-помощник для фотографов нового поколения.**
> Полный функциональный паритет с ботом «Яишка» Марины Яровой + суперсет возможностей: открытая база знаний, встроенная CRM клиентов, мультимодальный визуальный аудит и Web-студия.

---

## 🌟 Ключевые возможности

### 1. 🤝 Адаптивное знакомство и память (First-Launch Onboarding)
* **10-шаговый интерактивный бриф**: бот не выдумывает фейковых клиентов или шаблоны, а знакомится с реальным фотографом (имя, город, ниша, средний чек, клиенты, опыт, цели и стиль общения).
* **1-минутное голосовое знакомство**: возможность наговорить всё о себе одним голосовым сообщением — ProfileEngine автоматически структурирует и сохранит профиль.
* **Долгосрочная память (Episodic & Semantic Memory)**: бот помнит предпочтения фотографа, историю съемок, запретные слова и контекст работы.

### 2. 📸 4 ключевых домена фотобизнеса
* **Контент и соцсети**: живые сценарии Reels (с хуками на 0-2 сек), сторителлинги для Stories по шагам (Вход → Разворот → Детали → Опрос → Экспертность), посты без нейросетевых штампов и подбор музыки/треков под серию.
* **Продажи и клиенты**: оформление 3-уровневых прайсов (Лайт / Оптимальный / Премиум), скрипты отработки возражений (*«дорого»*, *«мы подумаем»*, *«не умеем позировать»*) без унизительных скидок, упаковка фотодней и сезонных предложений.
* **Съёмки и подготовка**: генерация мудбордов, цветовых палитр, подбор образов (гармония фактур, льна, трикотажа), сценариев съемок и тайминга.
* **Продвижение и упаковка**: аудит профиля и шапки, правило шахматного ритма ленты (*Дальний → Средний → Макро*), распаковка УТП и отстройка от конкурентов.

### 3. 🔍 Мультимодальный визуальный аудит (Vision Engine)
* Прямой анализ фотографий в чате через **Gemini Vision**:
  * Оценка композиции и кадрирования;
  * Анализ света, глубины теней и скинтона;
  * Разбор поз, взгляда и положения аксессуаров (часы, украшения);
  * Рекомендации по ретуши и финальной обработке кадра.

### 4. 📚 Открытая база знаний (Knowledge Ingestion Factory)
* В отличие от закрытых решений, система позволяет загружать **любые ваши материалы**:
  * PDF-гайды, презентации, чек-листы;
  * Конспекты курсов любых фотошкол;
  * Транскрипты видеоуроков и аудиозаписей.
* Гибридный поиск: векторный (ChromaDB / Dense Embeddings) + полнотекстовый (SQLite FTS5 / BM25).

### 5. 💼 Встроенная CRM клиентов и проектов
* Учет клиентов, статусов сделок, дат съемок и бюджетов.
* Проактивные напоминания (ProactiveEngine): бот напоминает о предстоящих съемках, брошенных лидах и предлагает свежие идеи контента.

## 🚀 Архитектура и интерфейсы

Система поддерживает одновременную работу через несколько каналов:
1. **Telegram-бот**: полная поддержка текста, голосовых сообщений, фото и удобного меню (src.brain.channels.telegram_runner).
2. **Web Studio SPA**: современная веб-панель управления на FastAPI/HTML5 (http://localhost:8000/).
3. **Open WebUI Federation**: стандартный OpenAI-совместимый API (/v1/chat/completions) для интеграции с Open WebUI.
4. **Interactive CLI**: терминальный режим для быстрой отладки (un_cli.py).

## 🛠️ Быстрый старт

### 1. Установка зависимостей
`ash
python -m pip install -r requirements.txt
`

### 2. Настройка окружения
Скопируйте пример конфигурации и укажите свои ключи:
`ash
cp .env.example .env
`
Заполните в .env:
* GEMINI_API_KEY — ключ Google Gemini API;
* TELEGRAM_BOT_TOKEN — токен бота от @BotFather.

### 3. Запуск сервисов
* **Web-студия + API**:
  `ash
  start_studio.bat
  # или: python -m uvicorn src.brain.api.app:app --host 0.0.0.0 --port 8000
  `
* **Telegram-бот**:
  `ash
  python -m src.brain.channels.telegram_runner
  `
* **Консольный режим**:
  `ash
  python run_cli.py
  `
