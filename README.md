# 🧠 Personal AI Brain

> Личный ИИ-напарник фотографа на Gemini 2.5 Flash с базой знаний по фотобизнесу.
> Все функции как у Яишки — только свое.

## ✨ Что умеет

| Функция | Описание |
|---|---|
| 🎬 Идеи Reels | Генерирует 5 идей Reels с хуком, визуалом и CTA |
| 💬 Ответ клиенту | Помогает ответить на любое сообщение/возражение |
| 📸 Мудборд | Составляет полный мудборд съёмки |
| ✨ Разбор аккаунта | Аудит профиля в Instagram |
| 🔍 Разбор фото | Анализ по 5 аспектам: свет, композиция, поза, цвет, эмоция |
| 🎵 Подбор треков | 4-5 треков для фотосессий/Reels/Stories |
| ⚖️ Спорная ситуация | Разбор конфликтов с клиентами |
| 📅 План дня | 3 приоритета |
| 💰 Прайс-лист | Три тарифа |
| 📝 Контент-план | План на 7 дней |
| 🎶 Голосовые | STT (распознаёт речь, воспринимает ответ) |
| 📎 Фотографии | Vision: разбор кадра/аудит аккаунта |
| 📄 Документы | Индексация PDF/DOCX/видео в KB |
| 🧠 Память | История диалога + RAG по базе знаний |
| 👤 Профиль | Ниша, город, цены, цели, тон голоса |

## 🚀 Быстрый запуск

```bash
# 1. Скопируй
 git clone https://github.com/Stas5252/personal-ai-brain.git
 cd personal-ai-brain

# 2. Настрой
 cp .env.example .env
 # Впиши GEMINI_API_KEY и TELEGRAM_BOT_TOKEN

# 3. Запусти
 docker compose up -d

# База знаний проиндексируется автоматически при первом старте
```

## 📦 Команды бота

| Команда | Действие |
|---|---|
| `/start` | Приветствие / профиль |
| `/profile` | Показать профиль |
| `/brief` | Обновить данные |
| `/reset` | Сбросить профиль |
| `/cancel` | Отмена |
| `/знания` | Добавить материал в KB |

## 📦 Структура

```
Dockerfile              # Мультимодальный контейнер
docker-compose.yml      # brain_api + telegram + open-webui
src/brain/
  ├── api/             # FastAPI (опенай протокол OpenAI)
  ├── channels/        # Telegram бот + Web адаптер
  ├── engines/         # 12 AI-движков
  ├── knowledge/       # Индексация, ChromaDB, RAG
  ├── prompts/         # Системный промт (фотобизнес)
  ├── services/        # BrainService
  └── knowledge/       # 16 KB-файлов с базой знаний
scripts/
  ├── seed_knowledge.py    # Индексация KB в ChromaDB
  └── docker_entrypoint.sh # автосидинг при старте
```

```env
BRAIN_DEFAULT_MODEL=gemini-2.5-flash

```
