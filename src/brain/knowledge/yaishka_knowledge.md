# Яишка — База знаний архитектуры и функций бота

## Общая архитектура

Яишка — AI-бот для фотографов и визуальных креаторов (доступ: @yaishka_access_bot).

### 4 главных раздела

1. **КОНТЕНТ** — создание материала для инстаграм
   - Идеи для Reels (хук, визуал, текст, CTA)
   - Контент-план на неделю
   - 9-шаговая сторис-арка
   - Подпись к фотографии
   - Хуки для постов и Reels
   - Сценарий Reels с таймкодами
   - Рубрикатор

2. **ПРОДАЖИ** — работа с клиентами и ценами
   - Ответ на возражения клиента (скрипт)
   - Спорная/конфликтная ситуация
   - Прайс-лист (правило 3 тарифов)
   - Договор с клиентом
   - Скрипт продажи в переписке
   - Коммерческое предложение
   - Реактивация спящих клиентов
   - Запрос отзыва

3. **СЪЁМКИ** — подготовка и организация
   - Мудборд съёмки (HEX, образы, локация)
   - Аудит аккаунта (Instagram)
   - Разбор фотографии (5 критериев)
   - Подбор треков
   - Образы клиента
   - Локации
   - План фотодня (9 шагов)
   - Бриф-анкета для клиента

4. **ПРОДВИЖЕНИЕ** — рост аккаунта
   - Стратегия продвижения
   - Коллаборации с другими авторами
   - Хэштеги (3 уровня)
   - Анализ конкурентов
   - Email/рассылка
   - Акции и офферы
   - Отзывы в контенте
   - План дня

## Ключевые функции

### Библиотека промптов (/library)
- Готовые промпты по 4 категориям
- Навигация с помощью кнопок
- Выбор по номеру для получения полного текста

### Мини-уроки (/uroki)
- 5 последовательных уроков по работе с ИИ
- Автоматическое перелистывание (не повторяются)
- Практические примеры

### Онбординг и профиль
- Голосовой или текстовый ввод
- Имя, город, ниша, цены, цели
- Профиль сохраняется между сессиями

### Голосовые сообщения
- Распознавание и транскрипция речи
- Голосовой ввод = текстовый запрос

### Анализ фотографий
- Разбор по 5 критериям
- Умное определение типа фото по caption
- Аудит профиля Instagram

### База знаний
- Загрузка PDF, DOCX, видео, аудио
- Индексация в ChromaDB
- Тематический поиск

### Напоминания
- Автоматические напоминания при неактивности 3+ дня
- 6 вариантов мессаджей
- После отправки — не дублируется

### Текстовый индикатор печатания
- Показывает анимацию «печатает...» во время обработки
- Обновляется каждые 4 секунды

## Команды

| Команда | Описание |
|---|---|
| /start | Запуск бота, приветствие |
| /profile | Показать профиль |
| /brief | Обновить профиль |
| /library | Библиотека промптов |
| /uroki | Мини-уроки |
| /help | Справка по командам |
| /reset | Сброс профиля |
| /знания | Загрузить документ |
| /cancel | Отмена ввода |

## Методология ответов

### Контент
- Reels: хук 0-3с, мясо 3-10с, детали 10-25с, CTA 25-30с
- Stories: 9 шаговая арка
- Посты: хук + история + ценность + CTA

### Продажи
- 3 тарифа: ЛАЙТ (база) | ОПТИМАЛЬНЫЙ (целевой) | ПРЕМИУМ (VIP)
- Без скидок: вариант — ограниченный пакет, не ниже цена
- Алгоритм работы с возражениями: признание → ценность → вариант

### Съемки
- Мудборд: концепция, HEX палитра, 7 образов, локация, 5 кадров, блок "Важно ♡"
- Анализ фото: свет, композиция, поза, цвет, техника
- Фотодень: утро, съемка, вечер
