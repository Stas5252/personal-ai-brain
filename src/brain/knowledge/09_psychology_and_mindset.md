# База знаний: Психология продаж и мышление фотографа

## ПСИХОЛОГИЯ БОЛЬШИХ ДЕНЕГ

### Почему фотографы мало зарабатывают:
1. **Синдром самозванца** — «я недостаточно хороша»
2. **Обесценивание** — скидки без причины
3. **Страх отказа** — не называют цену уверенно
4. **Сравнение с конкурентами** — смотрят вниз, а не вверх
5. **Ожидание «идеального момента»** — когда куплю объектив, похудею, съезжу на курс

### Установки, которые мешают:
- «Я не могу брать столько, у меня нет опыта»
- «Клиенты не будут платить дороже»
- «Кругом конкуренция, надо делать дешевле»
- «Мне стыдно просить деньги за хобби»

### Замена установок:
- «Я решаю реальную проблему клиента» → моя цена = ценность результата
- «Мои клиенты — те, кто ценит качество» → не все, только мои
- «Я имею право зарабатывать» → это профессия, не хобби

## НАШИ КЛИЕНТЫ — КТО ОНИ

### Портрет целевой аудитории фотографа:

**Сегмент 1: Мамы**
- Возраст: 25-40 лет
- Боли: дети растут быстро, нет хороших фото, муж не хочет фотографироваться
- Желание: красивые воспоминания, хвалиться перед подругами
- Триггер: скоро день рождения / новый год / событие

**Сегмент 2: Пары**
- Возраст: 20-35 лет
- Боли: нет красивых совместных фото, selfie не то
- Желание: красивое фото для соцсетей, подарок друг другу
- Триггер: годовщина, подготовка к свадьбе

**Сегмент 3: Женщины solo**
- Возраст: 28-45 лет
- Боли: нет уверенности, «фотогеничность», не знает что надеть
- Желание: фото для профиля, новый этап жизни, самовыражение
- Триггер: юбилей, смена работы, развод/новые отношения

**Сегмент 4: Бизнес/личный бренд**
- Возраст: 25-50 лет
- Боли: нет профессиональных фото для соцсетей
- Желание: выглядеть профессионально, иметь контент
- Триггер: запуск проекта, ребрендинг

## КАК РАБОТАТЬ СО СТРАХОМ ПЕРЕД КАМЕРОЙ

### Принципы:
1. **Никогда не торопи** — страх от спешки увеличивается
2. **Разговаривай** — молчание = напряжение
3. **Хвали конкретно**: не «хорошо», а «вот это выражение лица — идеально»
4. **Показывай кадры сразу** — клиент расслабляется, увидев себя
5. **Задавай вопросы** — человек в разговоре забывает о камере
6. **Давай задания, а не позы** — «посмотри туда», «иди ко мне», «обними его»

### Фразы для раскрепощения:
- «Ты не должна быть моделью — ты просто ты»
- «Камера снимает твоё внутреннее состояние»
- «Лучшие кадры — между позами»
- «Улыбайся не мне — вспомни что-то смешное»

## МЫШЛЕНИЕ УСПЕШНОГО ФОТОГРАФА

### Правила:
1. Не сравнивай себя с теми, кто дешевле — сравнивай с теми, кто дороже
2. Повышай ценность, а не снижай цену
3. Отказ клиента — это не провал, это фильтр
4. Инвестируй в обучение → растёт цена → растёт уверенность
5. Не работай с теми, кто не ценит

### Аффирмации для уверенного называния цены:
- «Моя цена — это результат, который я даю»
- «Правильный клиент заплатит правильную цену»
- «Я не оправдываю цену — я рассказываю о ценности»
