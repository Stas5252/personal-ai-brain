# База знаний: Идеи для Stories и контент-план

## 9-ШАГОВАЯ АРКА STORIES

### Шаг 1: ВХОД
- Яркий визуал или провокационный вопрос
- Первые 2 секунды решают всё
- Примеры: «Покажу вам кое-что важное», «Никому не рассказывала это»

### Шаг 2: РАЗВОРОТ
- Неожиданный поворот темы
- «Все думают, что… но на самом деле…»
- Создаёт интригу и желание смотреть дальше

### Шаг 3: ДЕТАЛИ
- Конкретика, факты, история из жизни
- Не «хорошо получилось» — а «клиентка плакала, увидев снимки»
- Детали создают доверие

### Шаг 4: ОПРОС
- «А у тебя так бывало?» / «Угадай, что ответила клиентка»
- Вовлекаем аудиторию активно
- Реакции поднимают охват

### Шаг 5: МОСТИК
- Связь личного опыта с универсальной темой
- «Это не только моя история — это история многих…»

### Шаг 6: РЕАКЦИЯ
- Покажи эмоцию: свою или клиента
- Видео-отзыв / скрин / «смотри как она отреагировала»

### Шаг 7: ФИЛОСОФИЯ
- Мысль, которая запоминается
- «Фото — это не тщеславие. Это архив твоей жизни»
- «Мы стареем — моменты остаются»

### Шаг 8: ЭКСПЕРТНОСТЬ
- Профессиональный совет / разбор / лайфхак
- «Вот почему большинство фото получаются скучными»

### Шаг 9: ОФФЕР
- Мягкий призыв к действию
- «Если хочешь такие же — напиши в Direct»
- «Посмотри свободные даты по ссылке»

## КОНТЕНТ-ПЛАН НА МЕСЯЦ (пример)

### Неделя 1: «ЗНАКОМСТВО»
- Пн: Личное — кто я, моя история
- Вт: За кулисами съёмки
- Ср: Образовательное — «3 ошибки при выборе образа»
- Чт: Кейс клиента + отзыв
- Пт: Опрос + вовлечение
- Сб: Свободные даты
- Вс: Вдохновение + личное

### Неделя 2: «ЭКСПЕРТНОСТЬ»
- Пн: Разбор ошибок в позах
- Вт: Мой рабочий процесс
- Ср: Топ локаций в городе
- Чт: Отзыв + кейс
- Пт: Обучающее видео / рилс
- Сб: Q&A — ответы на вопросы
- Вс: Личное / мысли

### Неделя 3: «СОЦИАЛЬНОЕ ДОКАЗАТЕЛЬСТВО»
- Пн: Кейс трансформации
- Вт: Скрины переписки с клиентами
- Ср: Видео-отзыв клиентки
- Чт: До/После (конкретный кадр)
- Пт: «Почему мне доверяют» — факты
- Сб: Анонс записи
- Вс: Личное / за кадром

### Неделя 4: «ПРОДАЖА»
- Пн: Свободные даты + пакеты
- Вт: История клиента → переход к офферу
- Ср: Образовательное → мягкая продажа
- Чт: Акция / специальное предложение
- Пт: Последнее место / дедлайн
- Сб: Отзыв + призыв к записи
- Вс: Итоги месяца / благодарность

## ФОРМУЛЫ ТЕКСТОВ ДЛЯ STORIES

### Формула «Боль → Решение»:
```
[Описание боли аудитории]
↓
[Что произошло когда я/клиент решили это]
↓
[Как получить то же]
```

### Формула «История → Урок»:
```
[Конкретная история из практики]
↓
[Что я из этого вынесла]
↓
[Применение к читателю]
```

### Формула «Миф → Правда»:
```
Все думают: [популярное убеждение]
На самом деле: [правда от эксперта]
Доказательство: [пример/факт]
```

## ТЕХНИЧЕСКИЕ СОВЕТЫ ПО STORIES

### Длина:
- Оптимально: 5-9 Stories в серии
- Одна мысль = одна Stories
- Не перегружай текстом

### Время публикации:
- Утро: 8-10 (рабочие дни)
- Вечер: 19-22 (пик активности)
- Суббота: 11-14 (семейное время)

### Вовлечение:
- Минимум 2 интерактивных элемента в день
- Реагируй на ответы — это повышает охват
- Упоминай имена тех, кто ответил

### Навигация:
- Первые 3 Stories самые важные
- Используй стрелочки «листай дальше»
- Заканчивай серию чётким CTA
