# База знаний: Промты для ИИ (ChatGPT/Claude) для фотографа

## КАК ПРАВИЛЬНО ИСПОЛЬЗОВАТЬ ИИ

### Принцип «роль + задача + детали»:
```
Ты — [роль]. Твоя задача — [что сделать].
Контекст: [детали о бизнесе].
Формат ответа: [список/пост/сценарий].
```

---

## ПРОМТЫ ДЛЯ КОНТЕНТА

### Генерация постов:
```
Ты — копирайтер для фотографа-портретиста.
Напиши продающий пост для Instagram о [тема].
Аудитория: женщины 25-40 лет, мамы.
Стиль: тёплый, личный, без пафоса.
Длина: 150-200 слов.
Добавь призыв к действию в конце.
```

### Генерация идей для Stories:
```
Ты — контент-стратег для фотографа.
Придумай 10 идей для Stories, которые закрывают страх
«я нефотогеничная» у женщин 30-40 лет.
Каждая идея — конкретный формат (видео/фото/опрос/текст).
```

### Закрытие возражений:
```
Возражение клиента: «[вставь возражение]».
Напиши 3 варианта ответа в переписке:
1. Короткий (1-2 предложения)
2. С историей клиента
3. С цифрами и фактами
Стиль: уверенный, без оправданий, тёплый.
```

### Заголовки для постов:
```
Придумай 15 цепляющих заголовков для поста о [тема].
Целевая аудитория: [описание].
Используй форматы: вопрос, список, провокация, обещание.
```

---

## ПРОМТЫ ДЛЯ БИЗНЕСА

### Анализ конкурентов:
```
Проанализируй профиль фотографа по следующим критериям:
- Позиционирование
- Ценовой сегмент (если видно)
- Тип контента
- Сильные стороны
- Что можно улучшить

Профиль: [описание или скриншот]
```

### Составление прайса:
```
Я фотограф в [город], специализация [что снимаю].
Опыт: [лет]. Средний чек конкурентов: [сумма].
Помоги составить линейку из 3 пакетов:
- Стартовый (для входа)
- Основной (самый продаваемый)
- Премиум (максимум)
Опиши что входит в каждый и обоснуй цену.
```

### Скрипт продажи:
```
Напиши скрипт ответа на запрос в директе:
«Сколько стоит фотосессия?»
Цель: не называть цену сразу, а выявить потребность и
предложить оптимальный вариант.
Мой стиль: [тёплый/деловой/дружеский].
```

---

## ПРОМТЫ ДЛЯ ОТВЕТОВ КЛИЕНТАМ

### Ответ на «дорого»:
```
Клиент написал: «Дорого, у другого фотографа дешевле»
Напиши 2 варианта ответа:
1. Мягкий (сохранить отношения)
2. Уверенный (объяснить ценность)
Без скидок, без оправданий.
```

### Ответ на негатив:
```
Клиент оставил негативный отзыв: «[вставь отзыв]»
Напиши ответ публично, который:
- Признаёт чувства клиента
- Не оправдывается
- Предлагает решение
- Выглядит профессионально для других читателей
```

### Письмо после съёмки:
```
Напиши сообщение клиенту после съёмки:
- Поблагодари
- Скажи что всё прошло хорошо
- Укажи срок отдачи
- Попроси разрешение на публикацию
- Тонко намекни на следующую съёмку
Длина: 3-4 предложения, тёплый стиль.
```

---

## КАК ОБУЧИТЬ ИИ НА СВОЙ СТИЛЬ

### Шаги:
1. Собери 5-10 своих лучших постов
2. Дай ИИ: «Изучи мой стиль письма по этим примерам:
   [вставь тексты]
   Теперь пиши в этом же стиле."
3. После каждой генерации: «Сделай более [тепло/коротко/с юмором]"
4. Сохраняй удачные промты в заметки

### Что НЕ делать:
- Публиковать текст ИИ без редактуры
- Использовать общие промты без контекста о себе
- Принимать первый вариант ответа
